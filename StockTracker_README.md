# CodeAlpha Stock Portfolio Tracker

A simple Python-based stock portfolio tracker that calculates total investment using predefined stock prices.

## Features

- Display available stocks and prices
- Add multiple stocks to a portfolio
- Calculate individual investment values
- Calculate grand total investment
- Validate stock names and quantities
- Save portfolio summary to a text file

## Technologies Used

- Python
- Dictionaries
- Lists
- Loops
- Conditional Statements
- File Handling
