# Basic Chatbot

## Description

Basic Chatbot is a simple rule-based chatbot developed using Python. It interacts with the user through the console and provides predefined responses based on the user's input.

## Features

- Greets the user
- Responds to common messages such as hello and hi
- Responds to "how are you"
- Provides information about the chatbot
- Displays help instructions
- Ends the conversation when the user says bye, exit, or quit
- Handles unknown inputs with a default response

## Concepts Used

- Python
- Functions
- While loops
- If-elif-else statements
- User input
- Output using `print()`
- String methods such as `lower()` and `strip()`

## How to Run

1. Make sure Python is installed on your system.
2. Open the project folder in a terminal.
3. Run the following command:

```bash
python basic_chatbot.py
```

## Example Interaction

```text
Hello! I am a basic chatbot.
You can say hello, ask how I am, or say bye.

You: hello
Bot: Hi! How can I help you?

You: how are you
Bot: I'm fine, thanks!

You: what is your name
Bot: I'm a basic Python chatbot.

You: bye
Bot: Goodbye!
```
